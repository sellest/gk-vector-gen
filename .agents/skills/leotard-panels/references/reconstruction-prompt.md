# Reconstruction prompt template

Input 1 is the client's approved garment design on a model. Input 2, if supplied,
is a silhouette/layout example, not a replacement for the design reference.

Produce clean flat print artwork for two separate garment panels: front on the
left, back on the right. Preserve [colors], [motifs], [logo text and placement],
[side graphics]. Use [silhouette reference] for panel shapes and relative layout.
Reconstruct a coherent continuation in hidden regions. Propose a back based on
the front's graphic language, with [back logo rule].

Orthographic 2D artwork, no body or person, no fabric folds, no perspective,
no material texture, no lighting or shadows. Retain gradients that are part of
the printed design. Crisp boundaries, ample outer margins, clear space between
panels, uniform #e6e6e6 exterior background or true transparency. No rulers,
labels, watermarks, dimensions, or technical annotations. Preserve full panel
edges including any white trim. Exact logo text: [verbatim text].

Record generated artwork as a draft. Iterate client changes without treating
the generated outline as a validated sewing pattern.
